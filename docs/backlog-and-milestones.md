## Iteration 3 · 9–15 November

Start PB-022 before PB-023 so release can require an approved claim. Agree on the claim states for PB-024 and PB-028 together. PB-025 can begin by testing the privacy controls already in place.

| ID | Work | Acceptance check |
| --- | --- | --- |
| PB-022 | Staff review and decision | Only authorized staff see private proof. The decision stores the reviewer and time. |
| PB-023 | Controlled release | An approved claim and a received item are required. Release logs the handover and blocks repeats. |
| PB-024 | Private claim status | The claimant can view the current stage. Another citizen gets no private details. |
| PB-025 | Sensitive field access | Public reads omit private contact details, ownership proof, and restricted custody fields. |
| PB-026 | Staff audit view | Authorized staff can view report and custody events in time order with actor and event type. |
| PB-027 | Basic suggestions | Use category, area, and date to suggest candidate reports. Show that suggestions require verification. |
| PB-028 | Claim history | Claimants can see the latest state, update time, and allowed next action. |
