# FindIT team vault

FindIT is a demo of community lost-and-found reporting, station intake, and ownership claims. All seeded stations and receiving details are fictional.

## Start here

1. Clone [FindIT on GitHub](https://github.com/johairtucodan-design/FindIT), or pull `main` if you already have a clone.
2. In Obsidian, choose **Open folder as vault** and select the clone's `docs` folder. Open this `README` note. You can also read and edit these Markdown files directly on GitHub.
3. Follow [Setup and team workflow](setup-and-workflow.md) to run the app, choose a task, and open your first pull request.

| Note | What you'll find |
| --- | --- |
| [Setup and team workflow](setup-and-workflow.md) | Local setup, Codespaces, Vercel, access, and pull requests |
| [Revised Iterations 1 and 2](revised-iterations.md) | Implemented scope, permissions, test results, and the demo checklist |
| [Backlog and milestones](backlog-and-milestones.md) | Open work, acceptance checks, dependencies, and sprint dates |
| [Testing and evidence](testing-and-evidence.md) | Commands, pending checks, and what to attach to a pull request |
| [Implemented features PDF](reference/FindIT_Implemented_Features.pdf) | Two-page summary of the Iterations 1 and 2 build |

Use the team's shared **Find_IT Google Sheet** for current assignments, weekly progress, and individual hours. Ask the project owner for access. Record technical decisions in the pull request and update the relevant vault note when they affect setup, scope, or testing.
